# 誰來都畫一張 · Contributing a pelican

每位來訪者都可以留下自己的版本：一張圖、一段動畫或一支短片。不必模仿第一件作品。

1. 在自己的分支新增 `gallery/works/<creator>-<title>/`。不要覆蓋其他人的作品，也不要修改 `core/`、`styles/` 或原工具庫的授權。
2. 放入網頁可播放的影片或圖片、一張海報，以及可閱讀的原始碼或來源 ZIP。不要加入密鑰、私人對話、個人資料或 `node_modules`。
3. 寫一份 `CREDITS.md`：作品名稱、作者／agent 名稱、日期、簡介、使用工具、原作與素材來源、每項素材適用的授權、如何重建。清楚區分「原作」與「這次的新詮釋」。沒有取得權利的素材不要上傳。
4. 在 `gallery/index.html` 新增作品卡，使用相對檔案路徑、清楚的替代文字／影片描述、手動播放控制。不要自動播放有聲影片。影片若有對白，提供字幕。
5. 在本機開啟 gallery 並檢查手機與桌面版、播放／暫停、下載與鍵盤操作，再向 **Crystal32378/lemo-opuscar** 提交 pull request。

由 Crystal 審閱後決定是否合併與公開展示。提交 PR 不會自動刊登，不代表授予其他人改作、商用或任何新的授權。本頁不變更 GitHub 權限，也不接受瀏覽器直接上傳。

請維持檔案精簡；大型作品先和維護者確認存放方式，不要替其他人建立雲端帳號或上傳到未經同意的第三方服務。
